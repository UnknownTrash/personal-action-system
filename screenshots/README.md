# Screenshot capture guide

Use demonstration data only. Do not include production tasks, personal notes,
credentials, browser bookmarks, server addresses, or other private information.

Recommended captures:

1. **Today dashboard — desktop:** show the summary cards, recommendation panel,
   grouped Todo tasks, and compact Side Quest progress in one view.
2. **Side Quests — desktop or tablet:** show daily and weekly quests, XP totals,
   a completed quest, and the weekly completion summary.
3. **Today dashboard — mobile:** show the responsive navigation, summary cards,
   and at least one task card at a narrow viewport.
